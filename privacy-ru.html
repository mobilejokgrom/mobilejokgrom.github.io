Политика конфиденциальности

Приложение: Lengu (English Cards Jokgrom)
Последнее обновление: Июнь 2026

1. Общие положения

Настоящая Политика конфиденциальности описывает, как приложение Lengu ("Приложение") обрабатывает информацию пользователей в соответствии с Федеральным законом №152-ФЗ "О персональных данных".

2. Какую информацию мы собираем

Приложение НЕ собирает, НЕ хранит и НЕ передаёт персональные данные пользователей на сторонние серверы.

Все данные хранятся:

  • Локально на устройстве — в базе данных SQLite
  • В вашем аккаунте Google — при использовании функции синхронизации с Google Drive/Sheets
  • В вашем аккаунте Яндекс — при использовании функции синхронизации с Яндекс Диском

3. Работа с Google API

Приложение использует Google Sign-In и Google APIs для следующих целей:

  • Google Drive API: Сохранение и загрузка ваших списков слов
  • Google Sheets API: Экспорт и импорт данных в Google Таблицы

Приложение запрашивает доступ только к файлам, созданным самим приложением.

4. Работа с Яндекс API

Приложение использует Яндекс OAuth и Яндекс Диск API для следующих целей:

  • Яндекс Диск API: Сохранение и загрузка CSV-файлов с вашими словами

Приложение запрашивает доступ только к папке "Lengu" на вашем Яндекс Диске.

5. Разрешения приложения

Приложение запрашивает следующие разрешения:

  • INTERNET: Для авторизации через Google/Яндекс и синхронизации данных
  • ACCESS_NETWORK_STATE: Для проверки наличия интернет-соединения

6. Офлайн-работа

Приложение полностью функционирует без подключения к интернету. Интернет требуется только для:

  • Первоначальной авторизации в Google/Яндекс
  • Синхронизации данных с облачными сервисами
  • Озвучивания слов (используется системный TTS)

7. Безопасность данных

Все данные, синхронизируемые с Google и Яндекс, хранятся в ваших личных аккаунтах. Мы не имеем доступа к вашим данным и не передаём их третьим лицам.

Токены авторизации хранятся локально на устройстве в зашифрованном виде (EncryptedSharedPreferences).

8. Ваши права

Вы имеете полное право контролировать свои данные:

  • Можете отозвать доступ приложения к вашему аккаунту Google в настройках Google Account
  • Можете отозвать доступ приложения к вашему аккаунту Яндекс в настройках Яндекс ID
  • Можете удалить все данные приложения путём его удаления с устройства
  • Можете запросить информацию о хранящихся данных, написав на email

9. Возраст пользователей

Приложение предназначено для пользователей старше 14 лет. Мы не собираем данные от детей младше 14 лет.

10. Изменения в политике

Мы можем обновлять настоящую Политику конфиденциальности. Все изменения будут опубликованы на этой странице с указанием даты обновления.
